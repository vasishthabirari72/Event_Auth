# Event staff quick guides

Use the event's local address and your own staff login. Keep the laptop powered and
connected to the event Wi-Fi. Internet is unnecessary; connection to the laptop is essential.

## Check-in volunteer
1. Select the LIVE event and correct slot. Ask before opening face capture.
2. Scan one person. Compare their face and stored photo; confirm the identity yourself.
3. If uncertain or unrecognized, search by member ID/name/mobile. For ID-only members,
   check their member card or ask a committee member. Send unresolved cases to the admin.
4. Confirm once and download the signed coupon PDF. Printing is currently an ordinary
   PDF workflow; no thermal printer integration is installed.
5. If download fails, retry the same coupon. An already-issued message goes to the admin;
   do not create another member record to issue another entitlement.

Face identification is experimental. It never authorizes issuance without your confirmation.

## Counter volunteer
1. Select the event, slot and your assigned counter; start the QR camera or use a keyboard scanner.
2. Serve the displayed option only on a fresh green SERVE result.
3. ALREADY USED, INVALID, CANCELLED or EXPIRED: do not serve; send the member to the admin.
   WRONG COUNTER: direct them to the named counter.
4. Connection failure: pause. Retry preserves the uncertain request. RECOVERED reports
   an earlier outcome; it is not another serving instruction. Ask the admin if uncertain.
5. Keep each slip out of view after its result. Do not use screenshots of old green results
   as current approval. The server decides each redemption.

## Administrator
Before opening: verify staff roles/PINs, registrations/choices, counters, power, network,
PDF output and backup. Mark the prepared event LIVE only when desks are ready.

Use Dashboard for current counts and coupon history. Lookup redemption handles missing
slips through the same validation. Replace an unused coupon with a reason to cancel its
old QR and create one replacement. Download retry uses the same coupon. Used entitlements
cannot be reissued. Void cancels an unused slip. Log staff in under their own roles.

Walk-ins: add/reuse the member, register event choices, then send them to check-in.
Imported details never imply face consent. Face enrollment is optional; obtain consent
and guardian agreement for minors. Delete member removes personal/face records.

After serving ends: refresh counts, investigate exceptions, export counts CSV, then close
the event. Closure is final and expires unused slips. Make an encrypted backup and check
that a restore drill has been completed. Do not restore an older snapshot over an active event.
